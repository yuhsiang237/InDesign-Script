# Picture Batch Place

An InDesign script for batch placing multiple images into pages automatically.

## Features

- Batch import multiple images.
- Sort images by numeric filename (e.g. `-3, -2, -1, 0, 1, 2, 3`).
- Automatically create pages when needed.
- Place one image per page.
- Fit images to page size while maintaining aspect ratio.

## Usage

1. Open your InDesign document.
2. Run `Picture_Batch_Place.jsx`.
3. Select multiple images.
4. The script automatically sorts and places them into pages.

## Supported Formats

- TIFF
- JPG / JPEG
- PNG

## Requirements

Adobe InDesign
