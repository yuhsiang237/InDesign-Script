# InDesign-Script
This repository is used to collect InDesign scripts for my work.

## How to Install and Run an InDesign Script

1. Open Adobe InDesign.
2. Go to **Window → Utilities → Scripts**.
3. Right-click the **User** folder in the Scripts panel.
4. Select **Reveal in Explorer** (Windows) or **Reveal in Finder** (macOS).
5. Copy the `.jsx` script file into the User folder.
6. Return to InDesign.
7. Double-click the script in the Scripts panel to run it.

**Note:** You can install any InDesign `.jsx` script using this method.
